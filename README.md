# Light Shadow Knight — 3050 Portfolio

A static, responsive creator portfolio for **Light Shadow Knight**, presented as a futuristic 3050 creative node.

## Updated in this build

- Voice of the Forgotten now uses the supplied **Voice of the Forgotten** cover artwork.
- Removed the **Nikita's Birthday** project from the portfolio.
- **Drawn Worlds** is now clearly presented as a normal standalone artwork, not part of Voice of the Forgotten.
- Added a **View more artwork** link to the Light Arts gallery.
- Added a working project-request flow with mailto + web-mail fallback + copy-to-clipboard.
- AI projects are marked **[ IN PROGRESS ]**.
- GitHub Websites & Tools vault remains available.
- Instagram and GitHub links remain available.
- Favicon included.
- No `.env` or backend is required.

## Run

Open `index.html` directly, or serve the folder with any static web server.

## Project request

The form prepares an email addressed to `light162010@gmail.com`. If the device has no mail handler, the page provides **Copy request** and **Open web mail** fallback controls.
